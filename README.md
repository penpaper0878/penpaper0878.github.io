# penpaper0878.github.io

This repository only redirects. Its one job is to answer the addresses on
`penpaper0878.github.io` that no other site does, so nobody lands on GitHub's
"There isn't a GitHub Pages site here" page:

| Address | Goes to |
| --- | --- |
| `penpaper0878.github.io` | the writings |
| `…/instatements/…` (the repository's old name) | the same page under the current name |
| `…/my-writings/…` (wrong capitals) | the same page, spelled correctly |
| anything else unknown | the writings |

`404.html` and `index.html` are the same file. They ask GitHub for the current
name of the writings repository by its id, which never changes, so a future
rename needs no change here.

`instatements/sw.js` and `instatements/writings/sw.js` retire the offline
workers browsers still keep for the old address.

Nothing here needs editing. Do not delete this repository: the old address
would start showing 404 again.
